# genuinly-gen.github.io

This repo contains a small static site (single-page) used as a personal live preview for - gen -.

Structure:
- index.html
- styles.css
- script.js
- content.json  (edit to change text & social links)
- images/ (place your background.jpg and icons here)

Instructions:
1) To update text or socials, edit content.json and push to the repo.
2) To replace the background or icons, upload files to the images/ directory with these names:

   - images/gamebanana.png
   - images/youtube.png
   - images/discord.png
